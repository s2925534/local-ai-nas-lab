# Literature comparison

Use once you've summarised two or more sources individually (e.g. with
[`research-summary.md`](research-summary.md)) and need to compare them.

## Prompt

```
Compare these sources on the same topic.

Source A summary: <paste>
Source B summary: <paste>
(add more as needed)

Give me:
1. Where they agree
2. Where they disagree or use conflicting methodology
3. Which claims seem better supported, and why
4. Gaps neither source addresses, relevant to: <your research question>
```

## Notes

- Better fit for `qwen2.5:7b` than the small model.
- Feed in your own summaries rather than raw source text where possible — shorter, cleaner input
  produces a more focused comparison.
